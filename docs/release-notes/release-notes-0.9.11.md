Changes since 0.9.10:

### Track headers
- The role drawing in a track header no longer covers the M/S buttons or the pan slider. It hides as soon as the row is too short for it.

### Velocity lane
- The gesture hint is no longer written across the velocity lane. Hover over the "Velocity" label to see it.

### Toolbar
- The Feedback button says "Feedback" instead of a question mark, so it no longer looks like a help button.
