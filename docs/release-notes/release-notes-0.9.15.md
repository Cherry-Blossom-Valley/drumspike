# Drum Spike 0.9.15

Changes since 0.9.14:

### App

- Previous Hit is Option+Tab, as in Pro Tools; Shift+Tab no longer steps back. The page key L stays (#299).
- Every menu item with a shortcut shows it, also the plain keys: View > Velocity Lane V, Transport > Play/Stop Space, Hits > Next Hit Tab. While a text field or a dialog has the focus, the plain keys belong to the field: a typed V or Space inserts text and runs no command (#300).
