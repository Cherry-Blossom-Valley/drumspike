# Security policy

## Supported versions

Security fixes go into the latest release only. Update to the
[latest release](https://github.com/Cherry-Blossom-Valley/drumspike/releases/latest) before you report.

## Report a vulnerability

Please do not open a public issue. Use GitHub's private report instead:
[Report a vulnerability](https://github.com/Cherry-Blossom-Valley/drumspike/security/advisories/new)
(Security tab > "Report a vulnerability"). Describe the problem, the affected version and the
steps to reproduce it. We answer within a week and tell you when a fix is released.

## Scope

Drum Spike is a local macOS app. It opens audio files and project folders that you choose, has no
server, sends no telemetry and has no updater. Relevant reports are, for example, a crafted audio
or project file that makes the app crash, run code or write outside the chosen folders, or a
problem in the signed release files.
